# Shipped synthetic dataset

`dataset.csv` (943 rows: 583 benign, 360 malicious) is generated by `create_dataset.py` from templates and
hand-picked examples. It is the corpus on which the shipped models were trained and on which the original
99.47% accuracy was measured.

**It is not real-world data.** The "malicious" rows are synthetic patterns (for example, raw IP hosts such as
`30.30.30.30:8080/phish` and template domains). Some generated hosts may coincide with real, routable IP
addresses or registered domains owned by third parties. Their presence here is an artifact of the generator,
**not a claim that those hosts are, or were, malicious**. Do not use this file as a blocklist.

The benchmark is flawed by design: all benign URLs use HTTPS and 352 of the 360 malicious URLs use HTTP,
so the URL scheme alone reaches 99.15% accuracy. See `research/audit_experiments.py` and the real-world
evaluation in `research/realworld/`.
